# Svastida Fashion Store

Production-oriented custom women's fashion storefront and admin platform.

## Product goals
- Customer storefront with dynamic collections and products
- Cart and checkout without online payment
- WhatsApp click-to-chat ordering
- Secure admin product/order management
- Storage usage dashboard
- AI fabric-to-dress concept generation
- Responsive, accessible, performant luxury UI

## Planned stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase Auth + Postgres + Storage
- Vercel deployment
- Pluggable AI image-generation provider

## Development
This repository is being built in staged, tested phases. See docs/architecture.md for the baseline specification.
